# NoBroker Owner Property Listing — Feature Benchmark

## Purpose

Use this document as a benchmark to review our property-rental product.

Compare our existing features against the following NoBroker-style owner experience.

The goal is NOT to copy NoBroker blindly. Identify:

1. Which features our product already has.
2. Which features are missing.
3. Which features should be FREE.
4. Which features should be part of PAID owner plans.
5. Which features can be monetized separately.
6. Which features can provide better value than NoBroker.

---

# 1. FREE OWNER LISTING

A property owner should be able to list a rental property without paying.

## Property Listing

Owner should be able to:

* Create a property listing.
* Select property purpose:

  * Rent
  * Sale
  * PG/Hostel, if supported
* Enter property type:

  * Apartment
  * Independent house
  * Villa
  * Room
  * PG
  * Office/commercial, if supported
* Enter property title.
* Enter complete property address.
* Select location on map.
* Enter monthly rent.
* Enter security deposit.
* Enter maintenance charges.
* Select furnished/unfurnished/semi-furnished.
* Enter carpet/built-up area.
* Enter number of bedrooms.
* Enter number of bathrooms.
* Enter floor information.
* Enter total floors.
* Enter parking availability.
* Add amenities.
* Add property description.
* Upload multiple property photos.
* Add videos, if supported.
* Add availability date.
* Set preferred tenant type.
* Set tenant preferences.
* Set lease duration.
* Set minimum stay, if applicable.

## Free Listing

Free owner should get:

* Free property listing.
* Property verification.
* Property published on marketplace.
* Property searchable by tenants.
* Tenant enquiries.
* Tenant contact/request mechanism.
* Owner can respond to enquiries.
* Owner can communicate with interested tenants.
* Owner can schedule property visits.
* Owner can accept/reject enquiries.
* Owner can negotiate rent.
* Owner can mark property as rented.
* Owner can edit listing.
* Owner can pause/unpublish listing.
* Owner can delete listing.
* Owner can see listing status.
* Owner can see enquiry history.

## Free Listing Restrictions

The free plan should NOT automatically include premium services such as:

* Premium ranking.
* 5x visibility.
* Dedicated relationship manager.
* Professional photography.
* Field/property-showing assistant.
* Guaranteed tenant.
* Money-back guarantee.
* Assisted tenant screening.
* Dedicated marketing campaigns.

# 4. PAID OWNER PLAN — RELAX/BASIC PREMIUM

NoBroker's current Relax plan is ₹3,399 + GST and is listed as a 45-day plan. It includes enhanced visibility, Relationship Manager support, rent-agreement home delivery, website/Facebook promotion and phone-number privacy.

Our equivalent paid plan could include:

### Premium Visibility

* Boost listing ranking.
* Featured listing.
* Premium badge.
* Higher search placement.
* Increased listing exposure.
* "Featured Property" section.
* Priority placement in relevant searches.

### Relationship Manager / Assisted Support

* Dedicated support person.
* Help with tenant enquiries.
* Follow-up assistance.
* Help coordinate visits.
* Help with rental process.
* Owner support through phone/chat.

### Marketing

* Marketplace promotion.
* Website promotion.
* Social media promotion.
* Facebook/Instagram promotion, if commercially appropriate.
* Locality-based promotion.

### Privacy

* Hide owner's personal phone number.
* Use platform communication.
* Masked calling, if technically available.
* Spam protection.

### Rental Agreement

Possible premium service:

* Rental agreement generation.
* Digital agreement.
* Document assistance.
* Doorstep/home delivery where available.
* E-sign support.
* Registration support, if legally/service-wise supported.

# 5. PAID PLAN — SUPER RELAX

NoBroker's current Super Relax plan is ₹5,899 + GST and adds professional property photoshoot and field-assistant/property-showing support to the Relax features. It is listed as a 45-day plan.

Our equivalent plan should add:

## Professional Property Media

* Professional photography.
* Property photo enhancement.
* Better listing cover image.
* Professional video.
* 360° virtual tour, if supported.
* Floor-plan upload/generation, if supported.

## Property Visit Assistant

* Assign field/property assistant.
* Assistant coordinates visits.
* Assistant can show property to tenants.
* Owner doesn't need to attend every visit.
* Visit scheduling.
* Visit confirmation.
* Visit feedback.

## Lead Handling

* Initial lead screening.
* Follow-up with interested tenants.
* Visit reminders.
* Lead status management.

# 6. PAID PLAN — MONEYBACK / GUARANTEE

NoBroker's MoneyBack plan is currently ₹6,999 + GST and is listed as a 60-day plan. It includes enhanced visibility, Relationship Manager support and a tenant guarantee/refund mechanism, while not including the photoshoot and field assistant that come with Super Relax. The exact refund/guarantee conditions must be controlled by explicit terms and conditions.

Our equivalent plan could provide:

## Tenant Guarantee

Possible model:

* Owner gets enhanced exposure.
* Dedicated support.
* Lead follow-up.
* Tenant matching.
* Guaranteed tenant within defined conditions/time.
* If conditions are satisfied but tenant is not found, refund according to plan terms.

IMPORTANT:

Do NOT implement "100% refund" simply as a UI claim.

The backend must define:

* Eligibility.
* Property requirements.
* Owner responsibilities.
* Required availability.
* Response-time requirements.
* Rent-price limits.
* Location eligibility.
* Minimum listing duration.
* Number of required visits/lead responses.
* Refund conditions.
* Refund exclusions.
* Fraud/abuse prevention.

# 9. IMPORTANT PRODUCT DIFFERENTIATION

Do not just copy NoBroker.

Check whether our product can provide better features such as:

## Lead Quality

* Tenant KYC verification.
* Tenant profile.
* Employment information.
* Income range.
* Family/member count.
* Preferred move-in date.
* Previous rental history.
* Tenant verification status.

## Owner Safety

* Tenant KYC.
* Aadhaar/PAN verification where legally permitted.
* Police verification integration where legally available.
* Employment verification.
* Rental history.
* Fraud detection.
* Suspicious enquiry detection.

## Communication

* In-app chat.
* Masked calling.
* WhatsApp integration where legally/commercially supported.
* Automated enquiry notifications.
* Visit reminders.
* Follow-up reminders.

## Rental Management

After tenant is selected:

* Rental agreement.
* Digital signing.
* Deposit tracking.
* Rent payment tracking.
* Monthly rent reminders.
* Rent receipts.
* Maintenance requests.
* Tenant-owner communication.
* Lease expiry reminders.
* Renewal management.
* Notice-period tracking.
